# Implementation Plan: Fix Telegram Bot Conflict Error Handler

**Branch**: `002-fix-bot-conflict-handler` | **Date**: 2026-06-06 | **Spec**: [spec.md](spec.md)

## Summary

Register a PTB error handler in `build_application()` that shuts the bot down cleanly when a `telegram.error.Conflict` (HTTP 409) is received — indicating another instance is already polling — and logs a CRITICAL message. All other exceptions are logged at ERROR level and the bot continues. Additionally, add a pre-flight guard in `scripts/dev.sh` to kill any stale bot process before starting a new one.

## Implementation Tasks

### T001 — Add `_on_error` error handler to `app.py`

**File**: `src/finance/bots/telegram/app.py`

**Changes**:
1. Add module-level flag `_conflict_seen: bool = False`.
2. Add async function `_on_error(update: object, context: CallbackContext) -> None`:
   - If `isinstance(context.error, telegram.error.Conflict)` and not `_conflict_seen`:
     - Set `_conflict_seen = True`
     - Log `CRITICAL`: `"another bot instance is already running — shutting down"`
     - Schedule `asyncio.get_running_loop().create_task(context.application.stop())`
   - Else if not Conflict:
     - Log `ERROR` with `exc_info=context.error`
3. In `build_application()`, after all `add_handler` calls: `application.add_error_handler(_on_error)`.
4. In the CLI entry point (`src/finance/cli/app.py`, after `application.run_polling(...)`): add `if _conflict_seen: sys.exit(1)`.

**Imports to add**: `import asyncio`, `import telegram` (for `telegram.error.Conflict`).

**Note**: `_conflict_seen` must be reset to `False` at the top of `build_application()` (not module-level initialisation only) so tests that call `build_application()` multiple times in the same process don't carry state between runs.

### T002 — Add stale-process guard to `scripts/dev.sh`

**File**: `scripts/dev.sh`

**Change**: Before the `if [[ "$RUN_BOT" == "1" ]]; then` block, insert:

```bash
# Kill any stale finance bot process so we don't get a 409 Conflict.
if command -v pgrep &>/dev/null; then
  stale=$(pgrep -f "finance bot" 2>/dev/null | grep -v "^$$\$" || true)
  if [[ -n "$stale" ]]; then
    echo "[dev] killing stale bot process $stale"
    kill "$stale" 2>/dev/null || echo "[dev] warning: could not kill stale bot process $stale"
    sleep 0.5
  fi
fi
```
